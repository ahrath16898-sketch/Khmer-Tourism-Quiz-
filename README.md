# កម្រងសំណួរទេសចរណ៍ខ្មែរ

## ការពិពណ៌នាគម្រោង
ហ្គេមកម្រងសំណួរជ្រើសរើសចម្លើយអន្តរកម្ម ដែលត្រូវបានរចនាឡើងដើម្បីសាកល្បង និងពង្រីកចំណេះដឹងរបស់អ្នកអំពីបេតិកភណ្ឌវប្បធម៌ដ៏សម្បូរបែបរបស់កម្ពុជា កន្លែងទេសចរណ៍ដ៏ល្បីល្បាញ ម្ហូបអាហារ និងប្រវត្តិសាស្ត្រ។ កម្រងសំណួរបង្ហាញសំណួរអំពីទិដ្ឋភាពផ្សេងៗនៃកម្ពុជា ចាប់ពីអង្គរវត្តដ៏អស្ចារ្យ រហូតដល់ម្ហូបខ្មែរប្រពៃណី ដែលធ្វើឱ្យការរៀនសូត្រអំពីប្រទេសដ៏ស្រស់ស្អាតនេះក្លាយជារឿងសប្បាយ និងទាក់ទាញ។

## លក្ខណៈពិសេស
- សំណួរចំនួន ១០ អំពីទេសចរណ៍ និងវប្បធម៌កម្ពុជា
- ជម្រើសចម្លើយ ៣ សម្រាប់សំណួរនីមួយៗ
- ពិន្ទុ ១០ សម្រាប់ចម្លើយត្រឹមត្រូវនីមួយៗ
- មតិកែលម្អភ្លាមៗជាមួយសារត្រឹមត្រូវ/មិនត្រឹមត្រូវ
- អង្គហេតុគួរឱ្យចាប់អារម្មណ៍អំពីកម្ពុជាបន្ទាប់ពីសំណួរនីមួយៗ
- បង្ហាញពិន្ទុចុងក្រោយជាមួយកម្រិតលទ្ធផល
- ការផ្ទៀងផ្ទាត់ទិន្នន័យបញ្ចូលសម្រាប់ការបញ្ចូលទាំងអស់របស់អ្នកប្រើប្រាស់
- ជម្រើសលេងម្តងទៀត

##  កម្រិតពិន្ទុ
| ជួរពិន្ទុ | កម្រិត |
|-------------|-------|
| ៤០-៥០ ពិន្ទុ |  ពូកែ - អ្នកជំនាញទេសចរណ៍ខ្មែរ |
| ៣០-៣៩ ពិន្ទុ |  ល្អ - ស្គាល់កម្ពុជាច្បាស់ |
| ២០-២៩ ពិន្ទុ |  មធ្យម - បន្តរៀនបន្ថែម |
| ក្រោម ២០ ពិន្ទុ |  ត្រូវការអនុវត្តបន្ថែម |
